# Обновления безопасности MSHost Talk

Правила введены 14 ноября 2026. Ответственный за отслеживание и доставку — оператор MSHost.
Это порядок ручного сопровождения, а не действующая автоматическая доставка обновлений.

- Проверять security-выпуски Nextcloud Talk Desktop/Android и Electron перед
  каждым выпуском и не реже раза в неделю. Зафиксированный lock-файл обновлять
  после проверки совместимости; не подменять его неподтверждёнными версиями.
- Для подтверждённого критического/высокого риска целевой срок подготовки
  исправления — 24 часа после обнаружения; при невозможности соблюдать срок
  приостановить использование затронутого клиента до оценки оператором.
- Alpha.1/alpha.2 Desktop с открытыми P1-находками больше не выдавать как текущий
  выпуск. Архивные копии сохранены для воспроизведения; пользователям вручную
  передать alpha.3 и получить подтверждение обновления каждого устройства.
- Из переписки известно только об Android Redmi с alpha.2; установленная версия
  Windows и полный список устройств неизвестны. Оператор ведёт список версий
  устройств без паролей и токенов и проверяет его при каждом security-выпуске.
- До обычного распространения Windows нужен доверенный сертификат подписи
  издателя и защищённое обслуживание ключа. Текущий механизм сборки принимает
  `WINDOWS_SIGN_PARAMS`; `-RequireSignature` запрещает выпуск без валидной подписи.
  Сертификат в текущем пользовательском хранилище не найден; Authenticode и
  автоматическая доставка исправлений остаются открытыми ограничениями.
- Сборки alpha.3 подготовлены локально. Установка, распространение и подтверждение
  работы аккаунтов после обновления выполняются отдельно; подготовка ZIP/EXE/APK
  не означает, что старые установленные версии уже обновились.
